# 🎬 Demo 实战演练剧本

> **5 步演示完整业务路由**:坐席接听 → 管理层预警 → 业务办理 → 审查归档 → 报告交付
> 一句话:从"客户打电话"到"承诺达成"的端到端故事。

---

## Step 0 · 进入 demo(30 秒)

1. 打开 https://YOUR_ORG.github.io/consume-protection-demo/
2. 进入系统会自动在登录页,选 "坐席 · 张敏" 进入
3. 此时坐席工作台 `#/agent/desk` 已打开(主入口)

---

## Step 1 · 坐席接听 + 创建工单(2 分钟)

**目标**:模拟一次消费者来电完整流程

1. 停留在坐席工作台,右侧顶部点 **"模拟来电"** 按钮
2. 来电弹屏出现:
   - 客户:周志远(逾期 90 天)
   - 标签:**多次承诺未兑现** + **情绪激动**
3. 系统顶部 banner 自动显示 "⚠️ 首次预警"
4. 点击弹屏的 **"接通"** 按钮
5. 自动跳到 **客户画像页** `#/customer/C003`:
   - 顶部 banner:三色预警 + 命中规则列表
   - 显示历史工单 / 历史规则 / 三维标签预设
6. 在画像页点 **"快速建单"**:
   - 三维标签已自动选中(基于历史)
   - 重复工单检测会**触发** → alert 显示"已有同类工单 GD-... 正在处理中"
   - 点 "继续新建" → 输入诉求描述 → 点 **"提交建单"**
7. 工单创建成功,落地 → 状态变为"待审批 → 待关单"

**关键看点**:从预警触发到工单落地的完整链路。

---

## Step 2 · 管理层:预警 → 指令下达(2 分钟)

**目标**:演示管理层跨角色联动

1. 切到管理层:demo 顶部右上角"张敏" → 选 "管理层 · 陈强"
2. 进入 `#/manage/dashboard`,看到坐席新建的工单已统计在 KPI 卡片
3. 进入 `#/manage/alert`:
   - 顶部 banner 显示 **电话工作台(OPT-FIX P2-10)** 等
   - 在预警列表里,你刚生成的新预警 card 在最上面
4. 点该预警 **"进入处理"**:
   - 抽屉打开,显示完整预警信息
5. 在抽屉里:
   - 点 **"下达指令"** 折叠区:
     - 接收方角色:坐席
     - 内容:**请在 2 小时内安抚情绪 + 给到还款协商入口**
     - 紧急度:**高**
     - 截止时间:今天 18:00
   - 点 **"提交指令"**
6. 自动切回坐席账号:
   - 顶部 banner 立即出现:📥 新指令 · 请在 2 小时内...
   - 点 banner 的 **"我已知晓"** → 状态变成"已读"
   - 点 **"完成"** 注明:已联系客户达成初步共识

**关键看点**:**管理层可以实时给坐席发指令** + 坐席可在同页直接 ack/done。

---

## Step 3 · 坐席:发起业务申请(2 分钟)

**目标**:跨角色申请单流转

1. 仍坐席账号
2. 顶部右侧点 **"发起业务申请"** 橙色按钮:
   - 类型:协商还款
   - 标题:为 C003 协商 6 期还款
   - 申请说明:客户已表明失业,希望分 6 期
   - 前情提要:工单 GD-XXX
   - 客户:C003
   - 优先级:高
3. 提交 → 顶部 banner:"业务申请已提交:BA-... · 等待业务执行岗审批"
4. 切到 **业务执行岗 · 李伟**(右上角切换):
5. 进入 `#/business/apply`(业务执行岗菜单首位,刚加的项):
   - 你刚提交的 BA-... 在最上面
   - 状态:待审批 · 优先级:高
6. 点 **"批准"**:
   - 输入审批意见:同意启动协商流程
   - 自动调用 `useWorkflowStore.start({ kind: 'negotiate' })` → 启动一个完整协商工作流实例
   - 工作流进入 `apply` 节点 → 自动推进到 `trial_calc` → 推到 `approve` 节点

**关键看点**:**坐席发起 + 业务执行审批 = 自动启动工作流 + 多节点流程**。

---

## Step 4 · 业务执行:办理协商 → 标记完成(1 分钟)

**目标**:演示业务办理落地

1. 切到 **业务执行岗**(陈强下方有个 "业务执行 · 李伟" 角色):
2. 进入 `#/business/negotiate`:
   - 你刚启动的工作流实例在列表顶部(关联工单 GD-XXX)
3. 在表单输入:
   - 试算方案:6 期 × ¥2,500
   - 备注:客户已确认
4. 系统显示 **"已写入票据池"**(票据合同页面有这个工单)
5. 切换到 `#/business/desk`:
   - 工作流待办卡片:实例已显示在"已完成"区域

**关键看点**:**工作流 → 落地到工单状态 → 反映到工单池**。

---

## Step 5 · 审查归档 + 同步承诺 → 自动闭环(2 分钟)

**目标**:审查闭环 + 跨阶段承诺传播

1. 切到 **审查人员 · 刘丽**(右上角切换)
2. 进入 `#/review/pending`(待审查立项):
   - 你刚的工单 GD-XXX 已落入审查立项
3. 点击那条立项进入审查执行 `#/review/execute/R-XXXX`:
   - 顶部强制关联标准清单(必选 + 选)
   - 每个标准填 "通过 / 不通过" + 备注
   - 通过后页头出现 "提交审查结论"按钮
4. 点 **"提交审查结论"** → 弹出归档 modal:
   - 勾选 **"提交投诉管控同步承诺(OPT-FIX-3 P3-10)"** 折叠区
   - 填:
     - 指标:**新户投诉率**
     - 目标值:**≤ 0.5%**
     - 当前值:0.62%
     - 截止日:**2026-09-30**
     - 理由:6 月达到 0.62%,承诺 9 月底前达标
   - 点 **"确认归档"**
5. 自动跳到:
   - `#/review/promises`(投诉管控承诺跟踪):
     - 你刚创建的承诺 PRC-XXX 出现在列表顶部
     - follow-up 工单 GD-XXX 已自动生成
     - 显示 "工单已生成" 状态
6. 打开详情抽屉:
   - 发起 1 次 **新检查**:"本月投诉率 0.55% · 趋势向好"
   - 状态 → 跟踪中

**关键看点**:**审查 → 自动承诺 + 工单 + 跟踪检查 = 完整治理闭环**。

---

## Step 6 · 管理层:合规报告(可选,30 秒)

1. 切到管理层
2. 进入 `#/manage/rectify`(整改闭环页面):
   - 你刚的 BA → 协商工作流 → 审查承诺的所有节点会显示在整改时间线
3. 切换到 `#/manage/quality`(质检):
   - KPI 显示各项指标当下状态

**关键看点**:**所有节点可追溯,管理层对全链透明**。

## 🎯 演示亮点速记(给 demo 当唱演者用)

1. **三道防线完整可见**:审查归档 → 知识库(STEP 5)、整改 → 标准沉淀(STEP 6)、预警 → 指令 → 坐席(STEP 2)
2. **跨角色实时联动**:任何操作通过 store 自动反映在另一角色页(无需后端)
3. **工作流自动化**:审批/扣除/三方联络通过 `useWorkflowStore` 自动跳节点
4. **持久化**:所有数据 localStorage,刷页面不丢
5. **类型严格**:0 个 TS 错,改动一处 IDE 实时反馈
